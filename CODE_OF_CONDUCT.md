# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, accept feedback on
code gracefully, and do not harass or demean anyone. Harassment, personal
attacks and discriminatory language are not tolerated in issues, pull requests,
discussions or any other project space.

## Reporting and enforcement

Report unacceptable behavior to amin.abouee@gmail.com. Reports are handled
privately. Maintainers may edit or remove comments, close threads, or block
contributors who violate this code.
